# 桐 一括処理 (Kiri Batch)

日本語データベース「桐」の一括処理ファイルを VS Code で色分け表示する拡張機能です。

## 色分けの対象

| 対象 | 例 |
| --- | --- |
| コメント | `*` ／ `＊` で始まる行 |
| 制御構文 | `IF` `ELSE` `END` `ケース開始` `繰り返し` `条件` `分岐` `手続き実行` など |
| 命令 | 行頭の `表` `編集表` `行訂正` `フォーム呼び出し` など |
| 名札・手続き名 | `名札　メインメニュー` `手続き定義開始　エラー発生()` |
| 変数宣言 | `変数宣言　共通,文字列{…}` の `共通` `文字列` |
| 変数 | `&変数` ／ `＆変数` |
| 関数 | `#関数` ／ `＃関数` |
| 項目 | `[項目名]` ／ `［項目名］` |
| 文字列 | `"…"` `”…”` `“…”`（混在可） |
| パラメータ名 | `終了状態=` `モード＝` |

`ケース開始`〜`ケース終了`、`繰り返し`〜`繰り返し終了`、`IF`〜`END`、`手続き定義開始`〜`手続き定義終了` は折りたためます。
`Ctrl+/` で行頭に `*` を付け外しできます。

## ファイルとの関連付け

次の名前のファイルは、設定なしで自動的にこの言語として開きます（`package.json` の `filenamePatterns`）。

| パターン | 中身 |
| --- | --- |
| `*_cmx.txt` | 一括処理（.cmx）を書き出したもの |
| `*_kex.txt` | イベント処理（.kex）を書き出したもの |

上のパターンに当てはまらないファイルは、`files.associations` で個別に関連付けてください。

この言語のファイルは既定で Shift-JIS として開きます。

## 文法の変更

`scripts/build-grammar.js` を編集して `npm run build` を実行すると `syntaxes/kiri.tmLanguage.json` が再生成されます。
