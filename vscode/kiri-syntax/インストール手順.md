# 桐 一括処理 (Kiri Syntax) インストール手順

桐の一括処理・イベント処理ファイル（`.cmx` や `.kex` から書き出した `.txt`）を VS Code で開いたときに、命令・変数・コメントなどを色分けして表示する拡張機能です。インストールは5分ほどで終わります。

| | |
| --- | --- |
| 必要なもの | Visual Studio Code（バージョン 1.80 以降） |
| 使うファイル | `kiri-syntax-0.1.1.vsix`（約6KB） |
| 入手先 | [GitHub からダウンロード](https://github.com/muramoto1041/ai-komon-tools/raw/main/vscode/kiri-syntax/kiri-syntax-0.1.1.vsix) |

## インストール

1. **ファイルを保存する**
   上の入手先からダウンロードした（または受け取った）`kiri-syntax-0.1.1.vsix` を、デスクトップなど分かりやすい場所に保存します。

2. **拡張機能ビューを開く**
   VS Code を起動し、`Ctrl` + `Shift` + `X` を押します。左側に拡張機能の一覧が表示されます。

3. **VSIX ファイルを指定する**
   一覧の上にある「…」（その他の操作）をクリックし、「**VSIX からのインストール...**」を選びます。
   ファイルを選ぶ画面で、手順1で保存した `kiri-syntax-0.1.1.vsix` を選んで「インストール」を押します。

4. **VS Code を再読み込みする**
   右下に完了のメッセージが出たら、`Ctrl` + `Shift` + `P` を押して「**開発者: ウィンドウの再読み込み**」を実行します（VS Code を閉じて開き直しても同じです）。

### コマンドで入れる場合

ターミナル（PowerShell など）で、保存したフォルダに移動してから次を実行しても同じです。

```
code --install-extension kiri-syntax-0.1.1.vsix
```

## インストールできたか確認する

拡張機能の一覧（`Ctrl` + `Shift` + `X`）に「**桐 一括処理 (Kiri Syntax)**」が表示されていれば完了です。一括処理のファイルを開くと、命令・変数・関数・文字列・コメントなどに色が付きます。

```
* 日次処理のメニュー（表示例）
名札　メインメニュー
フォーム呼び出し ”日次処理.wfm”，ボタン＝＆メインメニュー，終了状態＝＆確認
if(&確認<>1)
　　確認”入金元帳が開けません”
　　分岐　メニュー
end
&表番号＝#表番号取得（”売掛回収”）
```

実際の色は VS Code の配色テーマによって変わります。

## 色が付くファイル

次の名前で終わるファイルは、開くだけで自動的に色が付きます。設定は要りません。

| ファイル名の終わり | 中身 |
| --- | --- |
| `_cmx.txt` | 一括処理（.cmx）を書き出したもの |
| `_kex.txt` | イベント処理（.kex）を書き出したもの |

これ以外の名前のファイルは、普通のテキストとして開かれます。色を付けたいときは、ファイルを開いた状態で画面右下の「プレーン テキスト」をクリックし、一覧から「**桐 一括処理**」を選びます。文字化けした場合は、下の「困ったとき」の手順で Shift JIS で開き直してください。

## 困ったとき

### 日本語が文字化けする

画面右下の「UTF-8」と表示されている所をクリックし、「**エンコード付きで再度開く**」→「**Japanese (Shift JIS)**」を選びます。

「エンコード付きで保存」で UTF-8 を選ぶと、桐がファイルを読めなくなります。保存のときは Shift JIS のままにしてください。

### 色が付かない

画面右下の言語の表示が「桐 一括処理」になっているか確認してください。「プレーン テキスト」のままなら、ファイル名が上の「色が付くファイル」の表に当てはまるか確認してください。当てはまらない場合は、同じ節の手順で手動で切り替えます。

### VS Code で編集したのに桐の動きが変わらない

.txt は桐のファイルから書き出したテキストです。VS Code で書き換えても、桐側に取り込み直すまで桐の動作には反映されません。

## 新しい版を受け取ったとき・削除したいとき

- **更新：** 新しい `.vsix` ファイルを入手したら、「インストール」と同じ手順で入れてください。古い版は自動的に置き換わります。最新版は [GitHub の ai-komon-tools](https://github.com/muramoto1041/ai-komon-tools/tree/main/vscode/kiri-syntax) にあります。
- **削除：** 拡張機能の一覧で「桐 一括処理 (Kiri Syntax)」を右クリックし、「アンインストール」を選びます。
- **旧名「桐 一括処理 (Kiri Batch)」を入れている場合：** 名前が変わったため、自動では置き換わりません。拡張機能の一覧で「桐 一括処理 (Kiri Batch)」をアンインストールしてから、Kiri Syntax を入れてください。両方が入っていると、どちらの色分けが使われるか決まりません。
