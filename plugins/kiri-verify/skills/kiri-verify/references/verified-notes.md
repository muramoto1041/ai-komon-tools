# ヘルプで確認済みの書式メモ

2026-10-15 に桐オンラインヘルプ（kthree.co.jp/kihelp）で確認した内容。
ここにあるコマンドは、毎回ページを読み直さなくてよい。指摘の根拠にするときや、
内容に疑問があるときは、ページ（`cmd/stx/<page>.html`）を読み直して確かめる。

## 一括処理の書き方（cmd/bas/cmdb01）

- コマンド名と最初のパラメータの間は、半角・全角どちらかの空白で区切る。パラメータ同士は半角・全角どちらかのコンマで区切る。
- 行末の `\` で次の行に続ける。最後の行には付けない。1行は最大8000文字。
- 変数名は先頭に `&`（半角・全角どちらでも可）、最大64文字。全角/半角・大文字/小文字は区別する。
- オブジェクト名は `@` を付け、全角/半角・大文字/小文字を区別する。
- 属性名は引用符で囲まない。全角/半角は区別せず、大文字/小文字は区別する（半角カナの `ﾌｫﾝﾄｻｲｽﾞ` も可）。
- `終了状態=` の変数は 整数・長整数・数値・通貨・実数 のいずれか。**一括処理中のエラーを継続して処理するには、このパラメータが必要。**
- ヘルプに記載のない事項：コマンド名・パラメータ名の省略形、半角カナの扱い。

## 実行制御

- **手続き実行**（cprocn, 別名 call）：`手続き実行 名前( 式, … )`。条件付きは `手続き実行 ( <条件式> )，名前( … )`。**条件式の後にカンマが必要。** 参照引数には同じデータ型の変数を渡す。
- **分岐**（ccbranch, 別名 goto）：`分岐 <名札名>`、条件付きは `分岐 ( <条件式> )，<名札名>`。カンマが必要。手続き名へは分岐できない。
- **名札**（cclabel2）：`<名札名>：`。手続き内で定義した名札は、その手続きの中でだけ有効。
- **繰り返し**（ccfor）：`繰り返し <変数> = <開始>，<終了>，<加算>`。加算は省略でき、そのときは ±1。別名は `for … end`。
- **繰り返し中止**（ccwhileb）：別名 `break`。繰り返しの範囲の中でだけ使える。
- **if**（ccif）：`if ( ) … else if ( ) … else … end`。end で閉じる。
- **ケース開始**（csws）：別名は switch / case / default / end。`ケース その他` で「どれにも当てはまらない場合」を書ける。
- **エラー処理**（cergoto）：`エラー処理 <名札名> | 手続き名 = <手続き名>`。引数なしで解除する。**手続き内では名札を指定できない**（`手続き名=` を使う）。指定した手続きの中では &errno, &lineno, &cmdname, &errmsg, &detail を参照できる。
- **コマンド**（cccmd, 別名 eval）：文字列を1コマンドとして実行する。繰り返し・ケース・if・手続き定義・名札・コマンド自身は文字列で実行できない。
- **ライブラリ**（cclib, 別名 load）：拡張子を省略すると .cmx が付く。.kex は指定できない。イベントでは**メイン処理でのみ**使える。最大8ファイル。取り込めるのは `手続き定義開始` で定義した手続きだけ。手続き実行は、まず自分のファイル内を探し、なければライブラリを探す。
- **手続き定義開始（ハンドラ）**（ceprocsh, 別名 proc）：`<オブジェクト名>::<イベント名>( 型 変数 | 参照 型 変数 )`。メイン処理の中には書けない。
- **終了**（ccsave）：一括処理を終了する。**イベントでは使えない。**

## 変数

- **変数宣言**（cvarc）：`変数宣言 自動|局所|固有|共通, 型{ &名前 = 初期値, &配列[要素数] = { … } }, …`。型は 文字列・数値・通貨・整数・長整数・実数・日時・時間。種類を省略すると、手続き内では「自動」、それ以外は「固有」になる。局所はイベントのメイン処理でのみ宣言できる。同じ `{ }` 内で同じ名前を重複させた場合については記載がない。
- **代入**（cvarset）：コマンド名は省略できる。カンマで区切ると左から順に代入する。同じ名前の変数は「自動 → 局所 → 固有 → 共通」の順に探す。未宣言の変数への代入や、型の違う値の代入については記載がない。

## 表の操作

- **表**（copentbl）：`表 <ファイル>, 表番号=, モード=専有|共有更新|共有参照|参照, リトライ=する|しない, 索引名=, 使用フォーム=, 終了状態=`。終了状態は 1=成功、0=その他のエラー、-1=共有違反（リトライ=しない のとき）、-2=ファイル排他。**`変数使用=` パラメータはない**（結合コマンドだけにある）。
- **結合**（copenviw）：`結合 <定義ファイル>, <保存表名>, …, 変数使用=しない|する, 終了状態=`。保存表名を省略するときもカンマは残す（`結合 "x.vix",, …`）。
- **終了 表**（csavetbl）：`終了 表 * | <表番号>, … | 編集対象表`。表番号は定数か変数で指定する。`#IS表` などの関数で指定できるかは記載がない。
- **編集表**（cseltbl）：`編集表 <表番号> | <表ファイル名>`。拡張子を省略すると .tbx が付く。結合表を名前で指定するときは拡張子が必要。イベントハンドラが終わると、編集対象表はフォームの表に戻る。
- **項目属性変更２**（ctdfset2）：`変更, [項目], { 属性… }`。属性の位置は、1 名前、2 データ型、3 表示幅、4 被ふりがな項目、5 項目計算式、6 自動複写、7 更新、8 挿入初期値式、9 編集初期値式、10 値集合、11 表引き条件、12 字種条件、13 ガイドメッセージ、14 エラーメッセージ、15 項目制約式、16 行制約式、17 重複、18 未定義値、19 入力モード、20 編集モード、21 項目種別。属性を削除するときは `""` を指定する。他の利用者が表を開いていると実行できない。

## 行の操作

- **検索**（crfind）：`検索 [∨|↓|↑|∧,] <項目名>{ <比較式>, … } | <項目名>_<文字列変数>, …, 終了状態=`。終了状態は 1=あり、-1=なし。終了状態を省略して該当がないと、終端行に移る。**`[項目]=値` の形は記載がない。**
- **絞り込み**（crsval）：`絞り込み <項目名>{ <比較式>, … } | <項目名>_<文字列変数>`。変数に入れた比較式は `_` を付けて渡し、`{ }` で囲まない。0件でも絞り込み状態になる。&選択件数 に件数が入る。**`[項目] <= 値` の形は記載がない。**
- **行訂正**（credt）：`行訂正 終了状態=, [項目]=式, …`。終了状態は 1、0、-2=ファイル排他、-3=行ロック、-4=削除済み。終端行では実行できない。
- **行追加**（crapp）：`行追加 終了状態=, [項目]=式, …`。計算項目は指定できない。
- **ジャンプ 行番号**（crjmpn）：`= <番号> | +n | -n | 次行(N) | 前行(P) | 先頭(T) | 最終(B) | 終端(E)`。

## 入力・ウィンドウ・フォーム

- **メッセージボックス**（cmsg, 別名 msgbox）：`msgbox <タイトル>, <本文>, アイコン=i|?|!|E, ボタン指定=1..6, 制御文字展開=しない|する, <変数>`。押されたボタンの戻り値は 1=OK、2=キャンセル、3=中止、4=再試行、5=無視、6=はい、7=いいえ。**半角カナの `ｱｲｺﾝ=` / `ﾎﾞﾀﾝ=` はヘルプに記載がない。**
- **ウィンドウ情報取得**（cwinfo）：`<ハンドル>, 表名=<変数>, フォーム名=<変数>`。値はフルパスで入る。無効なハンドルを指定するとエラー。
- **ウィンドウリスト取得**（cwlist）：配列を渡すと、表示順にハンドルが入る。**[フォーム開始] ハンドラ内では結果が不定**になる。
- **ウィンドウ終了**（cwclose）：イベントを持つ自分自身のフォームは閉じられない。
- **オブジェクト操作**（cobjset, 別名 object）：`[ハンドル=,] @obj.属性 = 値 | @obj{ 属性=値, … }`。**一括処理から実行するときは `ハンドル=` を省略できない**（イベントハンドラ内で自分のフォームを操作する場合は省略できる）。
- **メソッド呼び出し**（cmethod, 別名 method）：ヘルプの表記は「メソッド呼び出し」。本文がほぼ空のため、書式は確認できない。「メソッド呼出し」の表記はヘルプに出てこない。

## ファイル操作

- **ファイル削除**（cfiledel）：`ファイル削除 <ファイル>, 終了状態=`。ワイルドカードを使える。終了状態は 0=正常、102=見つからない、111/175=使用中 など。開いている表や、表が使っているファイルは削除できない。
- **印字開始**（couts）：`印字開始 <ファイル>, 追加, 制御文字展開=, 文字コード=UTF16|UTF16BE|UTF8|UTF8NB|SJIS, 終了状態=`。終了状態は 1、0、-1=ロック中。
- **印字**（cout）：`印字 <式> | _<式>, …`。`_9` はタブ、`_13` は CR を出力する。末尾にカンマを付けると改行しない。
